# Bot-BaruBio

Herramientas internas de atención y protocolos.

| Carpeta | Contenido |
|---|---|
| `protocolos/` | Generador de protocolos y presupuestos (web estática). Se publica en GitHub Pages con `.github/workflows/pages.yml`. |
| `apps-script/` | Script de Google Sheets para compartir los precios entre dispositivos (ver `apps-script/LEEME.md`). |

El material privado (catálogo, fichas, conversaciones) vive en `Doc/` y está excluido del repositorio.
